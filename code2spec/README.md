Starfish is "a lightweight Web browser engine for TV, mobile, headless and wearable devices" ([`README.md`](src:README.md#L3)). This directory holds the code2spec Software Design Documentation (SDD) generated from the repository's source code under a zero-inference policy: every statement is grounded in a cited source location, and missing information is marked "Not specified in code".

Generation status: **W1 (discovery) complete** — system-level chapters, diagrams, and the functional-requirements index. Module Design Cards (`modules/`) and per-module functional-requirement documents are produced by W2 (`code2spec-modules`); interlinking, the quick reference, and validation are produced by W3 (`code2spec-finalize`).
