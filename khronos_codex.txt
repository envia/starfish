1. 3c2970edf — EXT_color_buffer_float 등록
------------------------------------------

가장 직접적인 테스트:

test/cairo/reftest/vendor/khronos/webgl/2.0.0/
  conformance2/extensions/ext-color-buffer-float.html

이 테스트는 다음을 직접 확인한다.

- getExtension("EXT_color_buffer_float") 반환값
- 같은 extension을 여러 번 요청했을 때의 일관성
- extension 활성화 전후의 float color-buffer 동작
- float texture/renderbuffer internal format
- texSubImage2D 및 readPixels 경로

현재 관련 결과 목록:

tool/reftest/cairo/khronos_webgl2.res:1510

WebGL 버전별 registry 노출 여부를 함께 검증할 때 중요한 테스트:

test/cairo/reftest/vendor/khronos/webgl/2.0.0/
  conformance2/extensions/promoted-extensions.html

현재 관련 결과 목록:

tool/reftest/cairo/khronos_webgl2.res:1513

보조 안정성 테스트:

test/cairo/reftest/vendor/khronos/webgl/2.0.0/
  conformance2/misc/getextension-while-pbo-bound-stability.html

현재 관련 결과 목록:

tool/reftest/cairo/khronos_webgl2.res:1550

주의할 점:

- 고정된 Khronos corpus에는 WebGL 1에서
  EXT_color_buffer_float가 반드시 null이어야 한다는 것을 직접 겨냥한
  테스트가 보이지 않는다.
- conformance/extensions/get-extension.html은 advertised extension과
  getExtension 결과의 일관성을 주로 검사하므로, WebGL 1에서 지원하면 안 되는
  extension을 양쪽 모두에 잘못 노출한 경우까지 잡아내지는 못한다.
- 따라서 WebGL 1 context에서는 EXT_color_buffer_float가 supported list에 없고
  getExtension도 null을 반환한다는 internal regression test가 필요하다.

------------------------------------------------

관련 회귀 테스트:

test/cairo/reftest/vendor/khronos/webgl/2.0.0/
  conformance2/textures/misc/tex-mipmap-levels.html

- PIXEL_PACK_BUFFER bind 여부
- offset overload 사용
- 음수 offset
- buffer range 및 buffer size 검증

- format/type 조합

현재 관련 결과 목록:

검사 범위:

- PACK_ROW_LENGTH

- PACK_SKIP_ROWS

khronos_webgl2.res에 포함되지 않은 것으로 보인다.

  conformance2/sync/sync-webgl-specific.html

현재 활성 상태:

이 테스트는 126df1bb4 자체를 직접 검증하는 것은 아니지만, TFJS가 사용하는

4. 65b32f585 — WebGL 1 float texture 크기 및 renderability 수정
-----------------------------------------------------------------

WebGL 1 FLOAT texture의 가장 직접적인 테스트:

test/cairo/reftest/vendor/khronos/webgl/1.0.3/
  conformance/extensions/oes-texture-float.html

검사 범위:

- OES_texture_float extension gating
- FLOAT typed-array upload
- null data upload
- texSubImage2D
- 지원되는 format/type 조합
- 선택적인 framebuffer attachment/readback 경로

현재 관련 결과 목록:

tool/reftest/cairo/khronos_webgl.res:63

WebGL 1 HALF_FLOAT_OES texture의 가장 직접적인 테스트:

test/cairo/reftest/vendor/khronos/webgl/1.0.3/
  conformance/extensions/oes-texture-half-float.html

검사 범위:

- OES_texture_half_float extension gating
- HALF_FLOAT_OES upload
- null/non-null data
- 지원되는 format
- 잘못된 typed array 전달
- 선택적인 framebuffer attachment

현재 관련 결과 목록:

tool/reftest/cairo/khronos_webgl.res:69

보조 테스트:

test/cairo/reftest/vendor/khronos/webgl/2.0.0/
  conformance/extensions/ext-color-buffer-half-float.html

현재 관련 결과 목록:

tool/reftest/cairo/khronos_webgl2.res:53

다만 Starfish가 EXT_color_buffer_half_float를 노출하지 않으면 이 테스트는
skip되므로 65b32f585의 핵심 회귀를 반드시 잡아준다고 볼 수는 없다.

중요한 coverage gap:

- oes-texture-float.html은 FLOAT texture를 framebuffer에 붙였을 때
  framebuffer가 incomplete인 구현도 합법적인 결과로 허용한다.
- 따라서 65b32f585의 TFJS 목적, 즉 WebGL 1에서 native
  EXT_color_buffer_float capability를 이용해 RGBA/FLOAT texture를 실제로
  renderable하게 만드는 동작은 이 Khronos 테스트만으로 강제되지 않는다.
- 다음 순서를 검증하는 internal regression test가 별도로 필요하다.

  1. WebGL 1 context 생성
  2. OES_texture_float 활성화
  3. RGBA/FLOAT texture 생성 및 upload
  4. framebuffer에 attach
  5. FRAMEBUFFER_COMPLETE 확인
  6. draw
  7. readPixels 결과값 확인

HALF_FLOAT_OES까지 같은 방식으로 지원하려는 경우에는 half-float용 테스트도
같은 구조로 추가하는 것이 좋다.

실행 방법
---------

xvfb-run -s '-screen 0 1920x1080x24' -a \
  ./tool/runner/test_runner.py \
  vendor_test_khronos vendor_test_khronos2

주의:

- 관련 테스트만 확인하려고 test runner의 -f 옵션을 사용하면 안 된다.
  이 옵션은 이번 패치와 무관한 모든 commented known-failure까지 강제로
  실행한다.
- .res에서 주석 처리된 항목은 추적 중인 known failure다. 단순히 테스트를
  green으로 만들 목적으로 삭제하거나 임의로 주석 상태를 바꾸면 안 된다.
- 테스트를 활성화할 때는 해당 항목만 수동으로 uncomment하고, 패치 전후
  결과를 비교한 뒤 실제 남은 실패를 다시 annotation해야 한다.
